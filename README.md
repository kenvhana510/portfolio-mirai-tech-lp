## 3. レスポンシブ対応内容

- **ナビゲーション**：1024px未満はハンバーガーメニュー＋フルスクリーン相当のドロップダウン、1024px以上は横並びのフルナビに切り替え。
- **モバイル固定CTA**：1024px未満で画面下部に「職場見学／応募する」を固定表示。`body`に`padding-bottom`を確保し、本文がCTAバーに隠れないよう対応。

- **横スクロール対策**：`body { overflow-x: hidden }`、固定px幅の排除（`max-width`ベースで統一）、`box-sizing: border-box`の全称適用で確認済み。

## 4. アニメーション

- **フェードアップ**：`IntersectionObserver`で画面内に入った要素へ`.is-visible`を付与し、CSS transitionで表示。一度表示した要素は`unobserve`し、余計な再計算を防止。
- **時間差表示**：カード・リスト等は`--delay`カスタムプロパティで0.05〜0.4秒ずつずらして表示。
- **数字カウントアップ**：働きやすさセクションの4指標を、ease-out-cubicで0→目標値までアニメーション。
- **STEPライン**：成長STEPセクションで、各ステップが画面内に入るとドットの色がグレー→ブルーに変化し、進行感を演出。
- **CTAホバー**：ボタンは`transform: translateY(-2px)` ＋ シャドウ強調のマイクロインタラクション。
- **`prefers-reduced-motion: reduce`対応**：該当設定のユーザーには、全アニメーションを即時表示・トランジションなしに切り替え。

## 7. SEO／アクセシビリティ対応

**SEO（基本）**
- `title` / `meta description` / OGPタグ（title・description・type・locale）
- 見出し構造：`h1`はFVに1つのみ、以降`h2`（セクション）→`h3`（カード等）の階層を厳守
- `JobPosting`構造化データ（JSON-LD）を実装し、求人LPとしてのSEO実務力を提示
- `meta name="robots" content="noindex, nofollow"`：ポートフォリオ公開時に検索エンジンへ誤って実在求人として索引されないよう設定（本番移行時は削除）

**アクセシビリティ**
- 「メインコンテンツへスキップ」リンク（キーボード操作者向け）
- フォームは`label`とすべての入力を`for`/`id`で正しく関連付け、ラジオボタンは`fieldset`/`legend`で構造化
- FAQは`<details>/<summary>`によるネイティブアコーディオン（追加JS不要でキーボード・スクリーンリーダーに対応）
- 全12枚の実写真には内容を説明する`alt`属性を付与済み（Stage A時点のプレースホルダーは`role="img"`＋`aria-label`で運用していたが、Stage Bで全画像を実写真に差し替えた際に`alt`属性へ移行済み）
- フォーカスリング（`:focus-visible`）を全インタラクティブ要素に表示
- ハンバーガーメニューは`aria-expanded`／`aria-controls`／Escキーで閉じる操作に対応
- カラーコントラスト：本文文字色（ネイビー系）と背景（白／ライトグレー）のコントラスト比を意識した配色

## 11. WordPress化する場合の移行方針

1. **テーマ構成**：`index.html`をベースに、`header.php`（HEADER）／`front-page.php`（FV〜CASE STUDY手前まで）／`footer.php`（FOOTER＋モバイル固定CTA）へ分割。
2. **セクションのモジュール化**：各セクションをACF（Advanced Custom Fields）のフレキシブルコンテンツ、またはカスタムブロック（Gutenberg）として登録し、コピー・画像・数値を管理画面から編集可能にする。
3. **画像**：`img-slot`プレースホルダーを`wp_get_attachment_image()`に置き換え、メディアライブラリ経由でアップロード・`alt`属性を管理。レスポンシブ画像（`srcset`）にも対応。
4. **フォーム**：Contain Form 7 または Gravity Forms等に置き換え、実際のメール送信・スプレッドシート連携を実装。現行のフォームUI・バリデーション仕様をそのまま踏襲。
5. **CSS/JS**：`style.css`・`main.js`はほぼそのまま`wp_enqueue_style` / `wp_enqueue_script`で読み込み可能（クラス設計・JSがWordPress依存になっていないため）。
6. **SEO**：構造化データ（JobPosting）はテンプレート内で動的に企業名・給与・勤務地を差し込む形に変更。`noindex`設定は本番公開時に解除。
7. **CV計測**：GA4／Google Tag Managerを`header.php`に追加し、フォーム送信・CTAクリックをイベント計測。
